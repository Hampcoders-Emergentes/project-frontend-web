# Role & access matrix

Roles are the `AccessRole` enum of the IAM user (`User`, `Admin`, `SuperAdmin`, `Maker`, `FieldManager`) and are carried in the JWT as `access_role` / `role` claims. The *business role* (`Technician`, `HomeOwner`, `Company`) comes from the completed profile (`businessRole` claim) and is enforced **inside** handlers (ownership checks), not by attributes.

Legend: ✅ allowed by role attribute · 🔑 any authenticated active user (additional ownership rules apply — see notes) · ⚙️ machine key · — not allowed
